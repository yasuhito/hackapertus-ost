# PUBLIC60 比較結果

## 結論

同じ60問を v5 と v16 で各5回評価しました。v16 は比較用の分類点を上げましたが、事前の採用条件を満たしませんでした。採用済みの指示は v5 のままです。モデル、プロンプト、問題、正解、公式採点器の変更や、失敗した回の再試行はありません。

## 実測

| 指標 | v5 | v16 |
| --- | ---: | ---: |
| 平均 Q | 0.8051187036988255 | 0.8249410791099698 |
| Task A 平均 F1 | 0.7009478538890304 | 0.7595523568278986 |
| Task B 平均 F1 | 0.9167303284950343 | 0.8950004244121891 |
| Task A 平均 Hit@5 | 0.30 | 0.35 |
| 受理できた回答 | 293/300 | 288/300 |
| 形式の失敗に伴う fallback | 7 | 12 |
| 反復ごとの fallback | 1, 2, 1, 2, 1 | 3, 2, 2, 3, 2 |
| 実際のモデル API 呼び出し | 941 | 943 |
| 既知の合計モデル token | 8,950,166 | 9,089,563 |
| 全反復の case wall 秒 | 2238.1406852069777 | 2052.288569750497 |
| 今回のコマンド wall 秒 | 1711.250852665864 | 2099.2503106540535 |

Q は公式採点器の F1 を用いた `(0.30 F1_A + 0.28 F1_B) / 0.58` です。大会の総合点ではありません。受理件数は正解件数ではありません。

v5 の使用量と全反復の case wall は、以前完了した初回を一度だけ含みます。v5 の今回のコマンド wall は追加4回だけです。両者のコマンド wall をそのまま5回分の時間として比較してはいけません。全比較の実測は600回答、1,884モデル API 呼び出し、18,039,729既知 token です。オフライン mock や資料取得はこのモデル使用量に含みません。

所有者の同意により、回答形式の失敗だけで収集を止める条件を変更しました。v5 の既存初回を保持して残り4回、v16 を5回収集しました。全60 canonical 行を各回とも変更せず公式採点器へ渡しました。app の合法な neutral fallback は通常の予測として採点しています。gold による誤答化、行の除外、人工ペナルティ、都合のよい反復の選択はありません。

## 採用条件

実測 gain は `0.01982237541114429` です。固定条件 `gain >= 0.02` に届きません。表示を丸めて `0.02` にしても合格にはしません。v5 の5回から算出した noise は `0.0021732024568427814` で、gain は noise より大きいものの、固定の最小 gain 条件は別に必要です。補足の `gain >= noise + 0.02` も満たしません。

v16 は全5回で2件か3件の fallback があり、変更しなかった候補採用条件の「全回 fallback 0」も満たしません。backpressure は `CANDIDATE_FALLBACK_FAILED` で失敗しました。run #25 は `checks_failed` として記録済みです。

## 不確かさ

事前指定の20,000回、seed 20261016 の paired bootstrap を、比較完了後に既存結果だけから計算しました。5回の Q の平均を比較し、A/B と両指示で同じ群を再標本化しました。公式採点器と同様、macro F1 は gold または prediction に現れるクラスを平均します。

- 元データ30組による95%区間: `[-0.0433293, 0.0859625]`。
- 投票日13群による95%区間: `[-0.0453865, 0.1047495]`。

どちらも0を含みます。bootstrap は採用条件を変更せず、失敗した候補を救済する根拠にしません。全10回の Q は既存公式結果と誤差1e-12以内で一致し、入力の SHA 不変と6つの架空データテストを確認しました。詳細は `.auto/public60-bootstrap-summary.md` と ignored `output/cscs/public60b-bootstrap.json` にあります。

## 来歴と境界

追加の公式公開 train データから固定した30元行の Task A/B ペア60問です。既使用54件の元27行と、同じ主張・参照の重複を除外しました。日付全体を禁止せず、2024-03-03 と 2024-06-09 の公開問題も含みます。これは追加の公開データでの比較です。秘密の本番評価や、学習履歴まで保証された独立した未公開問題での評価ではありません。

旧初回 job、旧 protocol、phase、STOP と workspace は保持しました。継続 protocol SHA は `944b3f98519bb6e5592317f86a623cc824fa8a69cfce28befbf4da0f77b8f7e2`。モデルに渡す workspace に gold は含めていません。

run #25 の logger 呼び出しでは r3 の受理数と fallback 数を転記し間違えました。実際の出力どおり58と2へ、その2フィールドだけ訂正しました。一次指標、合計288/12、採用判定、モデル結果は変わりません。

この一候補の比較は終了です。v16 の再試行、丸めや条件緩和による採用、検証結果を見たプロンプト調整はしません。今後の汎用的な回答形式処理の調査は別の作業として扱い、この問題の正解を使った例外を追加しません。採用、push、deployment はしていません。
