# How to Submit a Project

#### **General**

#### 👉🏼 Submissions will be handled on our Website (not on Devpost):
[https://hackapertus.ch/online-hack/submissions](https://hackapertus.ch/online-hack/submissions)

👉🏼 Submissions are open until **16 October/12:00 CEST (noon, no extension😇)**

#### **Submitting your Project

**Github repo template:

[https://github.com/HackApertus/project-template](https://github.com/HackApertus/project-template)

- When submitting your project, make sure to fill out all the given fields.
We provide templates for the technical report, dataset and Github repo.
Please check the respective challenge details for submission requirements.

**
Your submission must:**

1. follow the template repo and include all prerequisite files and definitions

1. follow the specified input/output format

1. run in a docker container launched with the specified CLI entry point

1. run end-to-end when the judges try to run it
