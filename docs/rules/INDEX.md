# Hack Apertus rules archive

Fetch date: **2026-10-12**

Public, unauthenticated archival snapshot. No login, registration, or submission was performed.
HTML/PDF originals are preserved where available. Markdown contains full source text, not summaries,
with source URL and fetch date at the top. Binary/original-file provenance is recorded in this index.

The Notion guide was recursively traversed through block children, page references, database views,
and **active queryCollection results**. All 43 accessible pages are archived, including both tracks,
all five Track 2A challenges, the OST Solution API Guide, schedules, submission instructions,
recordings/slides entries, and mentor pages. General Information is a guide section; its Code of
Conduct entry links to the website. Stale database sort-order IDs were tried separately and are
listed honestly below; they are not in current active collection results.

FAQ accordions were captured individually (including both distinct “How do I register?” answers).
Submission selector and each of its 10 branches were read without entering data or submitting.
The site's original JS/CSS are retained alongside original HTML shells and full rendered snapshots.
Rendered HTML/Markdown is an archival reading copy, not a functioning offline website.

Notion attachment signing was attempted without authentication. Batch signing failed with a
cross-cell error, so files were signed individually. All linked PDFs were downloaded; ten optional
social-preview images could not be signed or downloaded. Signed URLs may expire after this snapshot;
the local files remain available. Original attachment identifiers and signing responses are retained
in `attachments-manifest.json` and `notion/api/`. Local `ost.pdf` and `uzh.pdf` are unchanged copies.
