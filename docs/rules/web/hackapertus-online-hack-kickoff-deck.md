## 1B — Swiss Voices.

Evaluate how Apertus adapts to the languages, dialects, knowledge and values of Switzerland.

01

### Input adaptation

Speech, dialects, accents, code-switching and transcription without losing local context.

02

### Domain knowledge

Factuality and hallucination rates in Swiss law, medicine and business workflows.

03

### Behavioural steering

Regional norms, tone, safety boundaries, local ethics and regulation.

## Your project must run.

### Use the project template

* Keep the expected folder structure
* Include your source code and configuration
* Add a clear README and deployment instructions
* Do not commit secrets or private credentials

### Make it run with Docker

* Provide a runnable Docker setup
* Document the exact start command
* List required environment variables
* Test from a clean environment before submitting

[GitHub project template](https://github.com/HackApertus/project-template)
