    Responsibly sourced datasets

    aiLights Association will only consider submissions of responsibly sourced datasets. The team submitting the dataset is henceforth referred to as the provider.

    For a dataset to be sourced responsibly, the provider should only include:

    1. data directly created by the provider
    2. and/or data that they have the right to publish

    Moreover:

    1. the dataset should have a license
    2. the licenses of all individual content items of the dataset should be stated
      1. if the dataset consists of different modalities, e.g. text data and audio recordings, licenses for text and audio content items should be stated
    3. if data was collected from human subjects, this should have been done with due care to comply with ethical norms and legal requirements, in particular GDPR
      1. a template of the consent form provided to data subjects must be included in the submission
      2. the consent form must explicitly state how the data can be used for AI purposes
      3. the provider must confirm that consent was obtained from all data subjects
      4. all submitted data must be anonymised, with personally identifiable information removed
    4. the provider must be able to honour any commitments made to data subjects during data collection (e.g. consent revocation)
