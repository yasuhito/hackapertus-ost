Evidence sufficiency policy: decide the relation to the complete claim, not whether the claim and source share a topic. Internally identify what each selected span establishes and which part of the claim it addresses. Entailment requires support for every material assertion; a compatible but unstated assertion remains unknown. Contradiction requires an established incompatibility, not merely a failure to establish entailment. A supported incompatible assertion can refute a compound claim even when another assertion is unknown. For non-neutral decisions, return the smallest sufficient set of provided span IDs, retaining a neighboring span when it supplies a required condition or attribution. Do not add spans solely for keyword overlap. If no supplied spans establish either the complete claim or an incompatibility with it, return neutral.
